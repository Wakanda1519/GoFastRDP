# 🖥️ GoFastRDP

**Windows-клиент для хранения RDP-подключений и запуска сеансов в один клик: группы адресов, профили с паролями в DPAPI, генерация `.rdp` и запуск `mstsc.exe` — всё в одном exe бинарнике**

## Почему GoFastRDP

Ближайшие аналоги — это комбайны: деревья групп, облачная синхронизация, плагины, десятки вкладок с настройками, половина которых никогда не используется. Чтобы просто открыть рабочий стол, приходится каждый раз пробираться через запутанный интерфейс.

GoFastRDP сознательно оставляет только то, что нужно каждый день:

* Три сущности вместо десяти: группа (адрес и параметры сеанса), профиль (логин, домен, пароль) и кнопка «Подключить».
* Никаких аккаунтов, подписок, облаков и регистрации — приложение не спрашивает ничего лишнего.
* Параметры сеанса уже настроены разумно (порт 3389, 1920x1080, буфер обмена), их можно не трогать вообще.
* Пароль вводится один раз: дальше подключение занимает один клик, без копирования из блокнота.
* Установка не нужна: один exe, данные в вашем профиле Windows, а удаление — это удалить файл и папку с данными.
* Все управление в одном окне: поиск, избранное и порядок профилей без скрытых меню и вложенных настроек.
* Код открыт и без телеметрии: видно, что наружу уходит только подключение к вашему RDP-серверу.

Если нужен именно RDP-клиент, а не платформа для управления инфраструктурой, — это тот случай.

## Особенности

* Один `GoFastRDP.exe`: HTML/JS/Tailwind встроены в бинарник через `go:embed`, установка не нужна.
* Группы подключений: адрес и общие параметры сеанса задаются один раз, внутри — профили с логином, доменом и паролем.
* Пароли шифруются DPAPI и никогда не возвращаются в интерфейс — наружу отдается только флаг «пароль сохранен».
* Подключение одним кликом: приложение само собирает временный `.rdp` (включая `password 51:b`) и запускает `mstsc.exe`.
* Избранные профили закрепляются сверху, остальные сортируются перетаскиванием.
* Поиск по группе, адресу, профилю и логину; состояние свернутых групп запоминается.
* Нативное окно и сплэш: интерфейс показывается уже отрисованным, без белой вспышки при старте.
* Автоматическая миграция старого плоского формата (version 1) с резервной копией исходного файла.
* Без телеметрии: сеть используется только для локального интерфейса (`127.0.0.1`) и указанного вами сервера.

## Ограничения

* Только **Windows 10/11 x64**: интерфейс работает через Microsoft Edge WebView2 Runtime.
* Пароли привязаны к учетной записи Windows (DPAPI): при переносе `connections.json` на другой компьютер или пользователя их нужно ввести заново.
* Пароль в `.rdp` — тот же DPAPI-блоб, который может расшифровать любой процесс, запущенный от вашего пользователя, поэтому файл сессии удаляется через 30 секунд после старта `mstsc.exe`.
* Сеанс открывает системный `mstsc.exe`: шлюзы, политики и сертификаты обрабатываются им, уровень проверки сервера — стандартный для Windows (`authentication level:i:2`).
* Нет синхронизации и экспорта: данные хранятся только локально.

## Установка

### Требования

* Windows 10+ (x64)
* Microsoft Edge WebView2 Runtime (в Windows 11 уже установлен)
* Для сборки: Go 1.26+ и gcc в PATH (cgo). Node.js не нужен.

### Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт скачивает закрепленный Tailwind CLI (v3.4.19, проверка SHA-256) и собирает `GoFastRDP.exe` со встроенными ассетами. Если CSS уже собран, достаточно `go build -trimpath -ldflags "-s -w -H windowsgui" -o GoFastRDP.exe .`

### Использование

1. Запустите `GoFastRDP.exe` — окно откроется с уже загруженным списком подключений.
2. Нажмите «Новая группа» и укажите адрес (IP или имя), порт (по умолчанию 3389) и параметры сеанса: разрешение, звук, буфер обмена, все мониторы.
3. Через «Добавить профиль» создайте профиль: название, пользователь, домен и пароль. Пароль шифруется сразу и обратно в интерфейс не попадает.
4. Выберите профиль и нажмите «Подключить» — приложение сгенерирует `.rdp` и запустит сеанс в `mstsc.exe`.
5. Данные лежат в `%APPDATA%\GoFastRDP\connections.json`; кнопка «Локальное хранилище» открывает папку. Рядом появляются `connections.json.bak`, а поврежденный файл переименовывается в `connections.json.corrupt-<дата>`.

## Вопрос - ответ

<details>
  <summary><b>Куда попадают пароли?</b></summary>
  <br>
  Пароль шифруется DPAPI (ключами вашей учетной записи Windows) и записывается в `connections.json` только в зашифрованном виде. В интерфейс он не возвращается — форма показывает лишь «Пароль сохранен и зашифрован». Расшифровка происходит в момент подключения, чтобы подставить его в `.rdp`.
</details>
<details>
  <summary><b>Чем это лучше сохраненных .rdp файлов?</b></summary>
  <br>
  Не нужно держать десятки файлов и вручную копировать пароли: адрес и параметры сеанса задаются в группе, а логины хранятся отдельными профилями. Сеанс запускается из одного окна, а временный `.rdp` создается и удаляется автоматически.
</details>
<details>
  <summary><b>Что будет, если перенести connections.json на другой компьютер?</b></summary>
  <br>
  Группы, адреса и логины переедут, а пароли — нет: DPAPI привязан к учетной записи Windows. При подключении приложение сообщит, что пароль не удалось расшифровать, и предложит ввести его заново в профиле.
</details>
<details>
  <summary><b>Где хранятся файлы сессии?</b></summary>
  <br>
  В `%LOCALAPPDATA%\GoFastRDP\sessions\`. Файл содержит DPAPI-защищенный пароль, поэтому удаляется через 30 секунд после запуска `mstsc.exe`, а остатки от предыдущих запусков чистятся при старте приложения.
</details>
<details>
  <summary><b>Приложение обращается в интернет?</b></summary>
  <br>
  Нет. Телеметрии и автообновлений нет: локальный сервер интерфейса слушает только `127.0.0.1`, а сетевые подключения выполняет системный `mstsc.exe` по указанному вами адресу.
</details>
<details>
  <summary><b>Что если файл подключений повредится?</b></summary>
  <br>
  Приложение не запустится «в пустоту» и не перезапишет данные: поврежденный файл переименовывается в `connections.json.corrupt-<дата>`, приложение стартует с пустым списком, а предыдущая удачная версия остается в `connections.json.bak`.
</details>
